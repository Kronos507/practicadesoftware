Manejo de SECTION

¿Cómo se usa?

El uso de la etiqueta Section agrupa elementos según su contenido formando, como su nombre lo dice, una sección. Se dice que Section crea bloques a partir de diferentes elementos que puede incluir un encabezado y un pie.

Principales características

Un documento web podría dividirse en secciones para un listado de noticias, información de contactos, etc.

Debemos asegurarnos que todo lo que se encuentre dentro de una etiqueta section tenga relación.

Se usa para crear contenidos independientes dentro de un documento web.

Consideraciones

Si la intención es sindicar el contenido de un elemento Section, es mejor usar el elemento article en su lugar...
